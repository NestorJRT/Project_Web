## Week 1 Log Entry

### 1. High-Level Goal

This week, we wanted to make our SDG 3 proposal easier to read and more presentable. We created **Nappy**, a simple responsive web idea that helps students track sleep, water intake, exercise, and mood.

### 2. The Interaction Log

**Interaction 1**

**AI Tool Used:** Codex (GPT-5)  
**Context and Prompts:** We shared the project requirements and explained that our page would focus on SDG 3: Health and Well-Being. Our proposal was a web app to track sleep, water, exercise, and mood. We then asked: "con el contexto que te compartimos y con el draft que ya tenemos hecho, ayudanos a hacerlo mas profesional y presentable dando a entender el porque de nuestro proyecto y como funcionara"  
**What the AI Generated:** It created the first version of `index.html` with the introduction, rationale, problem, solution, benefits, conclusion, and a simple mockup. It then made the proposal shorter while keeping the required sections.

**Interaction 2**

**AI Tool Used:** Codex (GPT-5)  
**Exact Initial Prompt:** "probemos esta paleta de colores para el proyecto, adaptala reemplazando los colores que ya tenemos con estos"  
**What the AI Generated:** It used the selected palette: Prussian Blue (`#031D44`), Deep Space Blue (`#04395E`), and Muted Teal (`#70A288`).

### 3. The Human Audit & Modifications

The first proposal had too much text, so we asked for a shorter and clearer version. We chose the colors, removed borders, made the cards smaller, and changed the name from **Vita** to **Nappy**. We also removed the advice feature because we want the first version to stay simple and possible to build this semester.

### 4. Integration & Learnings

The proposal is a responsive page in `index.html`. It uses sections for the proposal content and CSS classes for the cards, colors, and mobile layout. We learned that CSS variables help us reuse colors, CSS Grid keeps cards aligned, and media queries make the page work on smaller screens.
